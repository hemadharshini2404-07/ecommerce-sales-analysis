# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to identify sales trends, profitable categories, top-selling products, and regional performance.

## 🚀 Live Dashboard

[View Live E-Commerce Sales Dashboard](https://hemadharshini2404-07.github.io/ecommerce-sales-analysis/)

## Tools Used

- Excel
- SQL
- Python
- Pandas
- Matplotlib
- GitHub

## Dataset

The dataset contains e-commerce order information including:

- Order ID
- Order Date
- Customer Name
- Category
- Product
- Region
- Quantity
- Unit Price
- Sales
- Profit

## Analysis Performed

- Total Sales Analysis
- Total Profit Analysis
- Total Orders Analysis
- Category-wise Sales
- Region-wise Sales
- Product-wise Sales
- Category-wise Profit
- Monthly Sales Trend
- Top 5 Orders by Sales
